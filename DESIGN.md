# Work's visual identity

Work is the end-user home for the desktop, company brain, and mobile experiences
built on Catamorphic. It speaks to people with projects to pursue, across roles
and professions. The framework keeps its own identity at catamorphic.ai.

## Direction

Make space for ambitious work. Large, quiet typography and generous space sit
beside concrete examples of ordinary projects. The homepage is one line, the film, three
sentences and the download. The film, captured from the real desktop app with
a prepared demo project, plays on its own, silently and looped, inside a
hairline frame; one hover control pauses it, and reduced motion shows the
poster instead.

## Tokens

| Role | Value |
| --- | --- |
| Background | `#0a0a0b` |
| Surface | `#101012` |
| Raised surface | `#16161a` |
| Border | `#232329` |
| Strong border | `#33333b` |
| Text | `#e6e6e9` |
| Secondary text | `#9a9aa3` |
| Accent | `#f95225` |

Inter is the only type family. Headlines use medium weight with tight spacing;
body text is calm and readable. Corners distinguish controls (6px) from working
surfaces (10px). Orange identifies primary actions, focus, and the main product
example. Motion answers user interaction and respects reduced motion.

The mark is Inter's W (weight 800, dark ink) on the orange rounded square,
the same artwork as the desktop app icon, next to a bold "Work" wordmark
(Inter 700, tight tracking). Copy sets the product name in bold where it
appears in a sentence. The palette, radii and buttons are the desktop app's
own tokens, so the site and the app read as one product.

## Content

Lead with what people can accomplish, then explain the product. Keep availability
accurate: Mac Apple silicon preview, self-hosted company brain, connected mobile
web client. AI accounts
and provider charges are separate. Link to real releases and setup guidance;
do not invent signups, customers, testimonials, or platform availability.

## Where the words live

Messaging and capability claims appear in a handful of places. Change them
together; the site check catches dead links, not stale facts.

| What | Where |
| --- | --- |
| Headline, one-liner, brain line, philosophy paragraph | `site/index.html` (the hero, `#brain`, `#why`) |
| Link preview and search snippet ("The software for work.") | `site/index.html` and `site/404.html`: `<meta name="description">`, `og:description`; the card image `site/assets/og-card.png` carries only the mark |
| Structured data (name, price, license, platform, download) | the `application/ld+json` block in `site/index.html` |
| The agent guide: facts, capabilities, pointers into the repository | `site/llms.txt`; mirrored at the catamorphic repository root as `llms.txt` with relative links (keep both in step) |
| The same guide with the repository documents inlined | `site/llms-full.txt`, generated by `scripts/build_llms_full.py` from the file list at its top; rerun and commit when the guide or those documents change |
| The messages the agent menus send | the `href`s and `data-message` in `site/index.html` (`#ask-agent-menu`, `#brain-agent-menu`); the brain message points at the setup skill in the repository |
| The film | `site/assets/work-desktop-film.*`; produced by the announcement-video skill in the catamorphic repository, installed with a new `?v=` hash on every reference |
| GitHub metadata (description, homepage, topics) | `gh repo edit` on `opencx-labs/catamorphic` and `opencx-labs/work-software` |
| Install facts (platform, cask, DMG) | `site/llms.txt` Facts, the JSON-LD block, and the catamorphic `README.md` install section |

When a capability lands, changes or goes away: edit `site/llms.txt`, copy the
change to the repository's `llms.txt`, rebuild `llms-full.txt`, and reread the
headline and philosophy for anything they now overstate.
